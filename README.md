# tenda-f6-vulnerabilities
Security advisories and proof-of-concept for two vulnerabilities in the Tenda F6 (N300) wireless router, firmware V12.02.01.73 (HW V5.0): a CSRF in the web management interface (CWE-352) and administrator credential exposure via cleartext HTTP and reversible Base64 cookie storage (CWE-319/312/522). Responsibly disclosed to the vendor.
